# LuckyTicket365 — логотип

Веер из 5 вертикальных билетов — bronze → silver → gold → platinum → diamond,
золотой по центру. Под ним вординг **LuckyTicket365**.

## Цвета вординга

Весь `LuckyTicket365` — золотой градиент лендинга `#F8BD3E → #FFE6A3 → #F8BD3E`
(`--gradient-gold` из его `theme.css`), одной непрерывной проводкой на всё слово:
градиент задан в userSpace от левого края вординга до правого, поэтому блик
проходит по центру слова, а не повторяется на каждой части.

Для светлого фона — та же рампа в глубоких тонах (`GOLD_TEXT_DEEP`).

Шрифт — **Space Grotesk Bold**, тот же `--font-wordmark`, что в шапке лендинга
(не Gilroy: Gilroy там body-шрифт). Лежит рядом в `fonts/SpaceGrotesk-Bold.ttf`
— статический инстанс wght 700, снятый с вариативного сабсета next/font, чтобы
перегенерация не зависела от билд-кеша лендинга. В SVG текст переведён в кривые,
шрифт при рендере не нужен.

Бренд-градиент `BRAND_TEXT` (`#DE009B → #A32183 → #743DF5`) остался в
генераторах — если захочется вернуть посплитовую раскраску как в шапке.

## Фон

Ядро — violet glow `#5B2E88 → #2E2049 → #12101E`, поверх мягкие поля всех
акцентов проекта: `electric-purple` слева сверху, `electric-pink` слева снизу,
`teal` справа снизу (перекликается с diamond-билетом), золотой отсвет за
веером, по краям виньетка. Константа `BG_LAYERS` — общая для лок-апа, обложки
и иконки.

## Файлы — на настоящей арт-графике билетов

Веер собран из `public/assets/icons/tickets/*.webp` — тех же билетов, что в игре.

| Файл                                       | Где использовать                          |
| ------------------------------------------ | ----------------------------------------- |
| `luckyticket365-logo.svg/.png`             | **основной** — лок-ап на фирменном фоне   |
| `luckyticket365-logo-transparent.svg/.png` | тот же лок-ап без фона, на свой тёмный фон |
| `luckyticket365-logo-dark-text.svg/.png`   | светлый фон: документы, пресс-кит         |
| `luckyticket365-mark.svg/.png`             | только веер, без текста                   |
| `luckyticket365-icon.svg/.png`             | 1024×1024 — аватар бота/канала, app icon  |
| `luckyticket365-cover.svg/.png`            | 1200×630 — OG-картинка, обложка в соцсетях |

Арт билетов вшит внутрь SVG (webp в data-URI, ~580 КБ) — файл самодостаточен и
рисуется через `<img>`, но только в браузере: старые SVG-редакторы webp внутри
SVG не понимают. Для них — PNG рядом.

⚠️ Исходная арт-графика билетов горизонтальная, поэтому в вертикальном развороте
названия тиров (BRONZE / SILVER / …) читаются снизу вверх, а клевер повёрнут на
90°. Развернуть их обратно можно только новой отрисовкой самих билетов.

## Запасной комплект — векторный (`*-flat`)

Те же 5 билетов, перерисованные плоско, цвета тиров из `theme.css`, клевер на
золотом билете стоит вертикально. Нужен там, где детальная арт-графика
превращается в кашу или важен вес файла: favicon, иконка в хедере, watermark,
печать, размеры < 80 px.

`luckyticket365-logo-flat.svg`, `-flat-transparent.svg`, `-flat-dark-text.svg`,
`-mark-flat.svg`, `-icon-flat.svg` + PNG.

## Перегенерация

```bash
pip3 install fonttools                                   # один раз
python3 public/assets/images/logo/generate-logo.py       # вектор + wordmark.json
node    public/assets/images/logo/export-flat-png.mjs    # PNG для вектора
node    public/assets/images/logo/generate-logo-real.mjs # арт-версия + её PNG
```

Порядок важен: `generate-logo.py` кладёт рядом `wordmark.json` (контуры трёх
частей вординга), из которого node-скрипты берут текст.

Что правится константами вверху скриптов: `TIERS` (угол наклона билетов),
`CX/CY/PIVOT` (центр и радиус развёртки веера), `H`/`TICKET_SCALE` (размер
билета), `BRAND_TEXT`/`GOLD_TEXT`/`BG_LAYERS` (цвета). Вертикальность билетов
даёт `rotate(-90)` внутри группы билета.

⚠️ id градиента вординга — `g-gold-text`, не `g-gold`: последний занят золотым
тиром билета, при совпадении центральный билет во flat-версии бледнеет.
По той же причине все SVG используют одинаковые id — если инлайнить два файла
на одной странице, id надо префиксовать.
