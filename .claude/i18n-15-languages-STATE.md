## Открытые решения, которые принимаю сам

1. **Сигнатура `tx()`.** 18 позиционных аргументов × 268 вызовов нечитаемо.
   Решение: `LocalizedText` = `Record<Locale, string>`, `tx()` принимает объект
   `{ en, ru, de, … }`; недостающие языки берутся из отдельных словарей-наложений
   на язык, чтобы 268 строк не переписывать 15 раз в одном файле.
2. **`tests/i18n.test.ts`** — читать список из папки `messages/`, а не хардкодить.
   Убирает один источник дрейфа навсегда.
3. **Лендинг** — динамический `[locale]` вместо 120 файлов.

## Где остановился и как продолжить

**Остановился осознанно после армянского.** Причина — не техническая: пользователь
сказал, что недельный лимит на 17%, а каждый следующий язык стоит ~25k токенов
вывода только на `messages/<код>.json`. Обвязка + один полный язык + деплой —
цельная единица; недоделанный второй язык был бы хуже чистой точки останова.

**Чтобы продолжить с любого места:**

1. Английский словарь — `messages/en.json`, 1376 ключей, порядок фиксирован.
2. Сборщик — `scratchpad/merge-locale.mjs`: принимает `{start, values}` и
   сверяет плейсхолдеры на каждом слиянии, поэтому сдвиг массива не проедет молча.
   `node merge-locale.mjs . es chunk.json`
3. Куски армянского лежат рядом как образец: `hy-1.json` … `hy-6.json`.
4. Когда файл полный — добавить код в `locales` (`src/i18n/config.ts`) и только тогда.
   Тест «у каждого выбираемого языка есть словарь» не пустит раньше.
5. Задания бэкенда — заполнить `MILESTONE_TRANSLATIONS` в
   `src/tasks/milestones.i18n.ts` (ключ = id задания). Долив в прод-строки
   происходит сам на старте через `backfillTaskTranslations`.
6. Лендинг — новый словарь в `src/i18n/dictionaries.ts` плюс код в `locales`.
