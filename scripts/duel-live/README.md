# Живые прогоны дуэли (PvP)

Инструменты, которыми дуэль проверялась на проде 22.08.2026 — см. навык
`.claude/skills/new-pvp-game`. Все скрипты читают токен бота из
`../lucky-ticket-backend/.env` и подписывают initData тестового аккаунта
(id 6709953752, @AK00001KA — второй аккаунт пользователя); токен доступа живёт
~30 минут, каждый запуск логинится заново.

- `duel-live-player.mjs` — гость по API: ждёт лобби хозяина (`HOST_ID`) или вызов
  (`ONLY_INVITE=1`), входит, жмёт «готов», ходит, меряет паузу вскрытия.
- `duel-live-host.mjs` — хозяин по API: создаёт лобби, зовёт AK001, играет.
- `duel-inapp-invitee.mjs` — НАСТОЯЩИЙ прод-фронт в headless Chromium под тестовым
  аккаунтом (`#tgWebAppData`): сидит на главной, ждёт модалку вызова, принимает, играет.
- `duel-monitor.mjs` — лента событий из прод-БД (нужен `.dburl` из
  `railway variables --service Postgres --kv` → `DATABASE_PUBLIC_URL`) + пробы посторонним.
- `duel-run.mjs`, `duel-run2.mjs` — Playwright по моку на localhost:3000: весь цикл и
  приглашения/диплинк/возврат в матч.

🔴 Один аккаунт — один клиент за раз, если не проверяется именно «два устройства».
